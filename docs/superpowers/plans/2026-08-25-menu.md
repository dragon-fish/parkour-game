# ME 经典风格菜单 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 主菜单、Esc 暂停菜单、设置页，纯白+大红的 ME 视觉（波浪边、skew
按钮、蓝阴影氛围实验），设置持久化到 user://settings.cfg。

**Architecture:** 共享主题工厂（颜色/StyleBox/波浪 shader）+ 可复用菜单列
组件；PauseUi 自动加载覆盖所有关卡；SettingsStore 纯逻辑层可测；main_menu
成为新项目入口。

**Tech Stack:** Godot 4.7.1 GDScript + gdshader，GUT（`tools/run_tests.sh`）。

**Spec:** `docs/superpowers/specs/2026-08-25-menu-design.md`（唯一权威）。

## Global Constraints

- 分支 `feat/menu`；提交纯英文 Conventional Commits；headless 测试 only
  （`.engine/…/Godot --headless`，绝不开带窗）。
- 视觉常量集中在主题工厂，不许散落：品牌红 `#e90100`、文字蓝 `#2d557e`、
  暂停 backdrop `Color(0.90, 0.93, 0.97, 0.72)`、按钮 `StyleBoxFlat.skew`
  ≈ -3°（`skew = Vector2(-0.052, 0.0)`，tan(3°)）。
- **永不加模糊**（spec 的风格约束，作者定调）。
- 表现值不写断言：测试只钉结构不变量（暂停态、cfg 往返、场景切换、Esc
  消费），颜色/波形/布局零断言。
- UI 文案中文（游戏面向作者本人），代码注释英文。
- 每任务结束跑 `tools/run_tests.sh <相关模式>`；Task 6 收尾跑全量，基线是
  7 个已知失败（4 个存量文件），不得多一个。

### Task 1: 主题工厂与波浪边 shader

**Files:**
- Create: `scripts/ui/me_theme.gd`, `scripts/ui/edge_wave.gdshader`
- Test: `tests/test_menu.gd`（新建，本任务只放 cfg 往返之外的最小烟测）

**Interfaces:**
- Produces: `class_name MeTheme`（全 static）：
  `const BRAND_RED := Color("#e90100")`、`const TEXT_BLUE := Color("#2d557e")`、
  `const BACKDROP := Color(0.90, 0.93, 0.97, 0.72)`；
  `static func button_style(bg: Color) -> StyleBoxFlat`（含 skew）；
  `static func wave_material(amplitude_px: float) -> ShaderMaterial`
  （加载 edge_wave.gdshader，设 uniform）。
- shader uniforms：`amplitude_px`（默认 6.0）、`frequency`（默认 9.0）、
  `speed`（默认 0.8）、`seed_left`、`seed_right`。

- [ ] **Step 1: shader**——canvas_item；fragment 里
  `left = (sin(uv.y*f + T*s + seed_l) + 0.6*sin(uv.y*f*2.3 - T*s*1.7 + seed_l*2.0) + 0.35*sin(uv.y*f*4.7 + T*s*0.6)) / 1.95`
  归一后乘 `amplitude_px / 控件宽`（用 `1.0/SCREEN_PIXEL_SIZE` 不可得控件宽，
  改用 uniform `width_px`，wave_material 由调用者传 control size.x；或简化：
  amplitude 直接以 UV 比例传入——实现者选一种并在注释说明）。
  `if (UV.x < left_edge || UV.x > 1.0 - right_edge) discard;`
- [ ] **Step 2: me_theme.gd**——常量 + 两个工厂函数，全 static、无状态。
- [ ] **Step 3: 烟测**：`MeTheme.button_style(MeTheme.BRAND_RED)` 返回非空
  且 `skew.x < 0`；`wave_material(6.0)` 的 shader 资源加载成功。
- [ ] **Step 4: 跑测 + Commit** `feat(ui): the ME theme factory and edge-wave shader`

**Interfaces:**

### Task 3: 菜单列组件 + PauseUi 自动加载

**Files:**
- Create: `scripts/ui/me_menu_list.gd`, `scripts/ui/pause_ui.gd`
- Modify: `project.godot`（[autoload] 加 `PauseUi="*res://scripts/ui/pause_ui.gd"`），
  `scripts/player/player.gd`（移除 Esc 处理——先 grep 找到现有 Esc 段）
- Test: `tests/test_menu.gd` 追加

**Interfaces:**
- Produces: `MeMenuList`（VBoxContainer 子类）：`func set_items(items:
  Array[String])`、`signal chosen(index: int)`、键盘上下/回车 + 鼠标悬停
  点击；红底白字项、选中项白条深字（波浪边材质用 MeTheme.wave_material，
  红列全振幅、白条减半）。
  `PauseUi`（CanvasLayer autoload，`process_mode = PROCESS_MODE_ALWAYS`，
  `layer = 10`）：`func toggle_pause()`、`_unhandled_input` 消费 Esc；
  暂停 = `get_tree().paused = true` + backdrop + 列（继续/设置/回主菜单）
  + `Input.set_mouse_mode(VISIBLE)`；继续 = 反向 + 按当前 Arena 的
  `capture_mouse` 决定是否重捕获（`get_tree().current_scene` 上鸭子类型读，
  读不到默认捕获）。主菜单场景里 Esc 不响应（`current_scene` 是
  main_menu 时 toggle 直接 return——用 scene 的 class/名字判断，Task 5 定）。
- Consumes: Task 1 全部；SettingsStore.apply 在启动时调（PauseUi._ready
  是全局启动点，正好负责开机套用设置）。

- [ ] **Step 1: 失败测试**——toggle 后 `get_tree().paused == true` 且鼠标
  mode 为 VISIBLE（headless 下 mouse mode 可读）；再 toggle 恢复；Esc 的
  InputEventKey 喂给 PauseUi._unhandled_input 后 paused 翻转。
- [ ] **Step 2: 实现**（Player 的 Esc 段删除——grep `KEY_ESCAPE`/`ui_cancel`
  in scripts/player/，把行为迁走并在原处留一行英文注释指向 PauseUi）。
- [ ] **Step 3: 绿 + 回归 `tools/run_tests.sh input capture 2>/dev/null || true`
  （若无该套件跑 player 相关）+ Commit**
  `feat(ui): the pause menu -- every level gets Esc for free`
