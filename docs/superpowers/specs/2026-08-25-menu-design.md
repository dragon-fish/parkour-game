# 主菜单 / 暂停菜单 / 设置（ME 经典风格）设计

面子工程 v1。视觉完全照搬《镜之边缘》菜单语言，交互从简。

## 视觉规范（✅ 作者给定，参考图四张已收）

- **品牌红**：`#e90100`——菜单主色块、按钮底色、强调元素
- **文字蓝**：`#2d557e`——浅色面板上的正文/标签（设置页风格）
- **纯白**：红底上的文字、选中态的高亮条底色
- **选中态**：当前项变成**通栏白条 + 深色文字**（参考图 1/4 的「继续游戏」），
  非选中项为红底白字
- **按钮形变**：`skew(0deg, -3deg)` 的轻微平行四边形（右边略窄的梯形感）。
  v1 用 `StyleBoxFlat.skew` 做平行四边形近似，梯形收窄不追求
- **暂停背景**：偏蓝的半透明白 backdrop（初值 `Color(0.90, 0.93, 0.97, 0.72)`，
  旋钮化），盖在冻结的游戏画面上。**永不加模糊**——✅ 作者定调："ME的UI
  本来就没有高斯模糊，基本全是简单的几何形状与半透明……这种立派的画风也
  不适合模糊。" 这是风格约束，不是成本妥协，后续也不要"升级"它
- 字体：v1 用引擎默认字体加粗；正式字体（DIN 系）以后授权了再换
- **边缘水波动效**（✅ 作者）：主菜单/暂停菜单的大片红色块与白色选中条，
  **左右边缘带随机的水波浪动态**——一个 canvas_item shader：
  片元里按 `UV.x` 与 `边缘基线 + 噪声(UV.y × 频率 + TIME × 速度) × 振幅`
  比较裁掉/透明化边缘外的像素，左右两侧各自独立的噪声种子。噪声用
  两三个错频正弦叠加即可（够"随机水感"且零采样）。uniform：振幅
  （初值 ~6 px @1080p）、频率、速度、左右各一相位种子。同一个 shader
  复用在红列与白条上，白条动得比红列更轻（振幅减半）

## 结构

三个场景 + 一个自动加载：

1. **`scenes/ui/main_menu.tscn`**（新项目入口场景，project.godot 的
   main_scene 指向它）——**构图参照鹰角《终末地》标题屏（✅ 作者补图）、
   配色仍是 ME**：
   - 近白背景
   - **地板点阵**：下半屏一层透视点阵网格，各点亮度**随机律动**
     （canvas shader：透视投影的网格采样 + 按格点哈希的相位脉动；
     uniform：间距、消失点高度、脉动速度、强度）
   - **中心主角剪影**：SubViewport 渲染玩家模型**背对镜头播放行走循环**
     （UAL Walk），材质整体 override 成 unshaded 纯色——用**品牌红**，
     正好是 ME 加载页红剪影的活化版，两家风格在此合流。模型来源沿用
     Arena 的 BODY_PROFILE/local.cfg 运行时加载模式（仓库无模型时剪影
     优雅缺席，菜单其余照常）
   - 左侧仍是 ME 红色纵列：**开始**（load main.tscn；以后换关卡选择）、
     **设置**、**退出**
   - 标题字：项目名粗体黑字 + 一条红色横向 accent 条（Endfield 黄条的
     红色版），v1 就是两个 Label + ColorRect

   **入场编排**（✅ 作者供的 Endfield 主菜单动画视频，已逐帧拆解 + 作者
   补充的起手式：特写 → 起身 → 标题与按钮渐显）：
   0a. **logo 版**（0–1s，✅ 作者点名 + 0/1/2s 逐帧核对）：项目 logo/
      标题字版压在**低头侧脸特写剪影**上（v1：粗体项目名 + 红条的简版
      字版即可），底部一条细加载条走 ~0.8s（假加载，纯演出）；点阵地板
      在角落刚开始渐显
   0b. **溶解与起身**（1–2s）：字版整体溶解（alpha out + 轻微上移），
      模型从低头/蹲姿起身（Crouch_Idle → idle 的现成过渡），相机同时
      ~1.2s ease-in-out 拉远绕到正后方全身位；红条从左右两缘各探入一小
      段（为下一拍的全幅扫入起势）
   1. 拉远完成时白底 + 点阵地板已全显（与相机运动重叠淡入）
   2. 0.2s **红色横条从左右两侧扫入**贯穿屏幕中带（0.3s，ease-out）
   3. 0.4s 标题块落位：先偏移 12px 再弹回，落位瞬间做 **1-2 帧错位抖动**
      （position 抖 ±3px 一次即可，廉价 glitch）
   4. 0.5s 起左列菜单项 **stagger 滑入**（每项错 30ms，ease-out 0.12s）
   5. 剪影人物同期淡入并持续行走循环
   6. idle：整体轻微漂移（sin 摆动 ±2px @ 0.1Hz），glitch 碎片偶发闪烁
      留 v2
   全部用 Tween 实现，无新增技术。

   **现代化改良五件套**（✅ 作者点头）：选中白条项间滑动（0.12s
   ease-out）；悬停项微右移 + 半透明白条预览；四角机能风元数据小字
   （版本号/构建号/`+` 定位符）；背景极淡纸感噪点（hash 一行）；底部
   按键提示 footer（`Esc 返回 · Enter 确认`）。适用于主菜单与暂停菜单。
2. **`scenes/ui/pause_menu.tscn` + 自动加载 `PauseUi`**（CanvasLayer，
   `process_mode = ALWAYS`）：任何关卡里按 Esc → `get_tree().paused = true`
   + backdrop + 居中红列（参考图 1 构图）：**继续**、**设置**、
   **回主菜单**。再按 Esc = 继续。自动加载意味着 debug_levels 白盒里
   也免费获得暂停菜单
3. **`scenes/ui/settings_menu.tscn`**（主菜单与暂停菜单共用，作为子页
   推入）：ME 设置页构图（参考图 3）——左列蓝字标签，中列控件，右上
   当前项说明文字；底部红钮 **默认 / 保存设置 / 取消**

### Esc 的归属链

现状 Esc 在 Player 手里（释放鼠标捕获）。改为：PauseUi 在
`_unhandled_input` 优先消费 Esc（暂停/继续）；鼠标捕获释放由暂停附带
（暂停=释放，继续=按关卡 capture_mouse 恢复）。Player 的 Esc 处理移除。

## 设置项（v1）与持久化

| 项 | 控件 | 落点 |
| --- | --- | --- |
| 窗口模式 | ←窗口化 / 全屏→ | DisplayServer window mode |
| 窗口大小 | ←1280×720 / 1600×900 / 1920×1080→（仅窗口化） | window_set_size |
| 鼠标灵敏度 | 滑条（红色填充段，参考图 3） | CameraConfig.mouse_sensitivity（找现有字段名） |
| 视野 FOV | 滑条，基准值（速度驱动区间跟随平移） | CameraConfig 基准 FOV 字段 |
| 总音量 | 滑条 | AudioServer master bus dB |

- 持久化：`user://settings.cfg`，启动时由 PauseUi 自动加载套用
- 与 WindowMemory 的关系：设置里改窗口大小 = 写同一份认知；WindowMemory
  照常记录手动拖动。两者都写 DisplayServer，后写者赢，无需仲裁逻辑
- 与 F1 调试面板互不相干：F1 是开发旋钮，设置是玩家偏好

## 顺带的氛围实验（独立小任务，可跳过）

✅ 作者："写个shader让游戏里的阴影颜色都带点这种偏蓝的感觉。" v1 用最便宜
的实现探路：base_level 的 WorldEnvironment 把 ambient light 调成偏蓝冷色
（阴影区由环境光主导，自然偏蓝），给 F1 一个色相/强度旋钮让作者拨。真
全屏 shader 调色（分离亮部暗部）如果这版不够味再立项。

## 明确不做（v1）

关卡选择、存档/章节、键位重绑、画质分级、多语言、加载页（红剪影那张
很帅，但我们没有加载时长）、背景 3D 城市景观、模糊 backdrop。

## 测试

结构不变量：暂停时 `get_tree().paused` 为真且输入被菜单消费；继续后恢复；
设置保存/加载往返一致（cfg 写读对称）；主菜单「开始」确实换到 main.tscn。
视觉（颜色、skew、布局）不写断言——表现值规则。
