## 一句话结论

镜之边缘的手感不来自"物理拟真"，而来自三个互相咬合的设计：

1. **速度是一条需要 7 秒才能爬满的曲线**，不是一个即时达到的常数；
2. **几乎每个动作都在损速**，跑酷技巧的本质是「用正确的动作把损速降到最低」；
3. **所有动作是显式状态机的节点**，而不是叠加在角色控制器上的一堆 if 分支。

详见 [10-镜之边缘-like判定标准](10-镜之边缘-like判定标准.md)。

## 单位速查

游戏使用 Unreal Units，本研究确认 **1 uu = 1 cm**（推导见 [09-Godot移植指南](09-Godot移植指南.md#单位换算)）。

| 量 | 游戏值 | 公制 |
|---|---|---|
| 最高奔跑速度 | 720 uu/s | 7.2 m/s ≈ 25.9 km/h |
| 重力 | **1600** uu/s² | **16.0** m/s²（配置写 800，实测生效值是其 2 倍） |
| 起跳初速度 | **630** uu/s | **6.3** m/s（跳高 **1.24 m**，滞空 **0.79 s**） |
| 眼高（相对碰撞体中心） | 76 uu | 0.76 m |
| 墙跑时长 | — | 约 1.65 s（顶点后 1.0 s 强制退出） |
| 墙跑垂直重力 | 790 / 505 uu/s² | 上升 / 下降，均远低于世界重力 |
| 墙跑最佳墙长 | — | **4–5 m**（顶点，出口最高且对时机宽容） |
