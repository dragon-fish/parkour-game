# Installation (GitHub Release)

**Requirements:** Godot **4.5+**

## Steps
1. Download the release ZIP and extract it.
2. Copy the folder `addons/godot_3d_cursor` into your Godot project so that it looks like this:

   `res://addons/godot_3d_cursor/`

3. Open your project in Godot.
4. Enable the plugin under:
   **Project Settings → Plugins → Godot 3D Cursor → Enable**

## Update
- Replace the existing `addons/godot_3d_cursor` folder with the new version.
- If issues occur, disable and re-enable the plugin or restart Godot.

## Uninstall
- Disable the plugin in **Project Settings → Plugins**
- Delete `res://addons/godot_3d_cursor/`

## Troubleshooting
- The plugin does not appear?  
  Make sure `plugin.cfg` exists at  
  `res://addons/godot_3d_cursor/plugin.cfg`
